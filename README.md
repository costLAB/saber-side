# saber-side
Saber Side: a multiplayer lightsaber game with Gorilla Tag-style controls

## Rustball (web prototype)

`index.html` is a single-file Three.js game: a rusty ball-bodied robot who lives on Ring Seven, an 800 ft spinning cylinder habitat. Open the file in a browser to play; it loads Three.js r128 and two Google Fonts from CDNs, so it needs an internet connection.

| Key | Action |
| --- | --- |
| ↑ ↓ | Roll forward / back |
| ← → | Turn |
| Shift (hold) | 5× speed |
| Space | Jump (in the hub: rise) |
| X | Spin attack |
| G | Pick up / drop, ride a lift |
| F | Use: ignite saber, fire blaster, bite carrot |
| Q E, drag | Orbit camera |
| − +, scroll | Zoom |
| C, double-click | Reset camera |
| R | Restack crates |

The ring is 800 ft across with an 85 ft hull, 400 ft long, and spins at 3.05 rpm for 1 g at the floor. Four lift tubes run from the promenade to a zero-gravity hub on the axis.
